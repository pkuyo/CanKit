## 0.1.0

### Added

* Initial release of `CanKit.Pro.RawCan` — part of the first published CanKit.Pro L2 stack. Provides the raw-CAN service layer: multi-protocol demultiplexing / subscriptions (`ICanBusService`, `ISubscription`) that give each protocol instance an independent, filtered read-only view of one `ICanBus` without competing over `ReceiveAsync`, plus TX-confirm (`SendConfirmed`).
