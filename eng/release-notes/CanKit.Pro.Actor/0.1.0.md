## 0.1.0

### Added

* Initial release of `CanKit.Pro.Actor` — the first published package of the CanKit.Pro L2 service stack. Provides a generic protocol-instance actor/scheduler: a single-mailbox, single-writer execution model with event-driven timer scheduling and a dedicated background-exception channel, giving protocol layers (ISO-TP, J1939, CANopen, ...) a documented threading model.
