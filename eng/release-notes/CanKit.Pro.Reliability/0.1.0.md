## 0.1.0

### Added

* Initial release of `CanKit.Pro.Reliability` — part of the first published CanKit.Pro L2 stack. Provides error/timeout infrastructure: a reusable actor-driven deadline primitive (`DeadlineScheduler`/`Deadline`) whose expiry is guaranteed to actually be checked and fired, plus a `BusStateMonitor` that pushes `ICanBus.BusState` transitions (ErrWarning/ErrPassive/BusOff and recovery) to protocol instances.
