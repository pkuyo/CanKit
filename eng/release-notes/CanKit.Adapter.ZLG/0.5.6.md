## 0.5.6

### Changed

* Updated the `CanKit.Core` dependency to 0.5.6.
* Cloud device and user names now use ANSI native marshalling.

### Fixed

* Cloud connection no longer recurses through its asynchronous entry point.
* Bus initialization tolerates reset operations that are unsupported by the device.
* Periodic transmission returns reserved auto-send indexes when construction fails.
* Infinite receive waits are preserved by the fake native backend.

### Breaking Changes

* None.
