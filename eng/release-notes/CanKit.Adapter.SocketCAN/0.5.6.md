## 0.5.6

### Changed

* Updated the `CanKit.Core` dependency to 0.5.6.
* Aligned BCM periodic update, query, and delete operations with Linux kernel behavior for Classic CAN and CAN FD frames.

### Fixed

* Periodic transmissions now retain their own frame memory and release native handles and buffers when setup fails.
* `RemainingCount` now handles asynchronous status replies, finite completion, and infinite jobs without spurious errors.
* Existing interfaces without controller mode information now fall back to static capabilities while genuine native errors still propagate.

### Breaking Changes

* None.
