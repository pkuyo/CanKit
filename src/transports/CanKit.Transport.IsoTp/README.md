# CanKit.Transport.IsoTp

This project is an experimental, unfinished ISO-TP transport prototype. It is not production-ready and must not be used for release-critical applications.

The project is intentionally not published to NuGet (`IsPackable=false`). It remains in the repository only as prototype source while the release-safe ISO-TP implementation is developed.

The prototype is expected to be superseded by the planned successor package `CanKit.Pro.IsoTp` (in progress on `develop`).
